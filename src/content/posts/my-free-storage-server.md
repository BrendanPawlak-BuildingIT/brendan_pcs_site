My college gave me these storage servers. On eBay, one of these costs about $500. By the way, these
can store 24 hard drives each. And I got two of them.

Okay, this one's pretty cool because it came with this RAID controller to connect and manage all of
these drives. It does look like a full ATX motherboard would fit — like this Z690 board that I have.

And this other one, I have some ideas. This one looks like it will fit a 360 mm liquid cooler, and
that should work.

I'm thinking about using this one to run Plex and Jellyfin for a dedicated media server. And then
maybe this second one for a NAS.
